# Tygodniowe-luksusowe-safari-w-Kenii-
Interactive Mapbox map of a week-long luxury safari in northern Kenya, covering Samburu, Kalama Conservancy, Laikipia (Ol Lentille) and Lewa Wildlife Conservancy, starting from Nairobi's Wilson Airport. It has a satellite view, an animated route and a clickable day-by-day itinerary
